#### Model Selection Rationale

Initially, the use of state-of-the-art closed-source LLMs was considered due to the limited size of the available training dataset. However, this approach was not pursued due to constraints in computational resources and accessibility.

Instead, an open-source multimodal LLM was selected, as it allows for local fine-tuning under the GPU limitations provided by the college.

The fine-tuning approach adopted is **QLoRA (Quantized Low-Rank Adaptation)**, which does not retrain the entire model but instead injects task-specific knowledge efficiently into a pre-trained model.

**Recommended: `Qwen/Qwen2.5-VL-32B-Instruct` with BitsAndBytes 4-bit quantization**

- VRAM at 4-bit: ~22GB weights + ~8GB overhead = ~30GB total — fits 48GB comfortably with headroom for QLoRA fine-tuning later
- **Why not gemma-4-31b-it**: Qwen2.5-VL is specifically optimised for document/OCR/table understanding (DocVQA, ChartQA benchmark leader). Switching families requires rewriting the processor/inference code and loses the proven document-extraction advantage. Qwen2.5-VL-32B is a 4.5× parameter upgrade on a family already tuned for this exact task.
- **Why not 72B**: QLoRA fine-tuning of 72B on a 48GB GPU is impractical. The user plans to fine-tune once training data collection is complete.
- Quantization: `BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_compute_dtype=torch.bfloat16, bnb_4bit_quant_type="nf4")`
---

#### Model Constraints and Selection

Given the available GPU resources (≤40GB VRAM), the model selection was restricted to:

* Models that fit within memory constraints
* Multimodal capability (handling both text and images)
* Strong benchmark performance (e.g., Artificial Analysis Intelligence Index)

Based on these criteria, **Qwen3-VL-8B-Instruct** was selected as the primary model candidate, as it demonstrates superior performance compared to models such as Llama3-8B and Mistral variants in multimodal reasoning tasks.

Current working model (for inference and pipeline development):
**Qwen2.5-VL-7B-Instruct**

---

#### Pipeline Design

**Input:**
Scientific PDF papers

**Output:**
Structured CSV records containing vector competence data

**Pipeline Workflow:**

1. Convert each PDF into page-level images
2. Use a multimodal model to process:

   * Full-page content
   * Cropped regions (tables, figures, captions)
3. Extract candidate records in a strict JSON schema
4. Store provenance metadata for each record, including:

   * PDF name
   * Page number
   * Source type (e.g., table, text, figure)
   * Evidence region
5. Perform manual review and correction of extracted records
6. Export reviewed records into CSV format consistent with the reference dataset
7. Store corrected records as additional training data for future fine-tuning

---

#### Current Stage

* Model usage: inference-based extraction
* Workflow: semi-automated data collection with manual validation
* Focus: building a high-quality dataset rather than full model training

Full fine-tuning (QLoRA) will be conducted after sufficient high-quality training data has been accumulated.

---

#### Summary

This project aims to develop a scalable pipeline for extracting ecological trait data from literature using multimodal LLMs. By combining automated extraction with manual validation and iterative fine-tuning, the system is designed to progressively improve both data coverage and extraction accuracy.

4. Discussion
This master’s thesis developed a multimodal extraction pipeline for West Nile virus vector competence data and applied it to a 50-paper literature corpus to produce a structured dataset suitable for comparative analysis. The central finding of the project is methodological as much as technical: biologically meaningful extraction depends not only on model strength, but on rigorous schema design, record integrity and ecologically informed evaluation.
One of the most important insights was that schema alignment is foundational. If candidate outputs contain fields that are absent from reviewed or gold records, then evaluation partly measures incompatibility of representation rather than real extraction quality. Restricting extraction to a schema directly aligned with the target dataset therefore improved interpretability and made the resulting records more useful for biological analysis.
A second major lesson concerns the biological meaning of a record. In vector competence work, a valid observation is not simply a set of numbers pulled from a paper. It is a treatment-specific combination of taxon, conditions and outcomes. Extraction quality therefore depends heavily on whether those treatment-level identities are preserved. This explains why record matching became such an important part of the workflow. Improving pairing with biologically relevant auxiliary variables did not weaken the standard of correctness; it reduced artefactual penalties due to structurally poor comparison.
The thesis is biologically meaningful because better access to structured vector competence data directly strengthens trait-based disease ecology. Competence is one of the most important determinants of whether a mosquito species can contribute to enzootic maintenance or spillover transmission, but its relevance is often obscured by how difficult the literature is to synthesise at scale. By improving the extraction and structuring of these data, the project helps remove a key bottleneck that limits broader comparative work, including VPI-style approaches that integrate competence with host use (Bauer et al., 2026). 
The project also shows why MLLMs should be used critically in ecological synthesis. Multimodal models are powerful tools for document interpretation, but they remain vulnerable to hallucinated structure, treatment merging and partial extraction. For numerically sensitive biological tasks, human validation remains essential. The human-in-the-loop design is therefore not a weakness of the thesis but one of its strengths, because it ensures that automation is deployed in a way that preserves biological reliability.
The final 50-paper design also reconnects this thesis to the broader VPI and One Health motivation. By constructing a larger, reviewed WNV competence dataset with global and European coverage, the project contributes directly to the trait data infrastructure needed for broader comparative analysis. Even where the immediate focus remains vector competence rather than host use, the study provides the extraction, schema and evaluation logic that later integrative analyses depend on.
Several limitations remain. The literature itself is heterogeneous, and not all papers present evidence in equally extractable forms. Some source ambiguity may remain even after review. In addition, while the final dataset supports broader comparative analysis, it still represents a subset of the total WNV literature. Nevertheless, the thesis demonstrates that multimodal extraction can meaningfully accelerate trait dataset construction when paired with rigorous review and evaluation.
Overall, the study argues that scalable biological literature extraction is not simply a matter of model benchmarking. It requires defining the correct biological record, aligning output structure to downstream analytical needs, and building an evaluation process that distinguishes genuine extraction error from artefacts introduced by schema mismatch or poor record matching. That is the principal methodological contribution of this master’s thesis.

5. Conclusion
This master’s thesis developed a multimodal, schema-constrained pipeline for extracting West Nile virus vector competence data from scientific literature and using the resulting structured data for broader comparative analysis. By combining PDF image processing, multimodal LLM extraction, manual review, parameter-efficient model adaptation and record-based evaluation, the project establishes a reproducible workflow for turning heterogeneous literature into structured biological evidence.
Its significance is both technical and biological. Technically, it demonstrates how multimodal models can be adapted for scientific document extraction under realistic hardware constraints. Biologically, it improves the trait data infrastructure needed for comparative work on WNV vectors and for broader frameworks such as the Vector Potential Index. The thesis therefore contributes not only a practical extraction system but also a methodological argument for how AI-assisted ecological data synthesis should be designed.
